Titanic Streamlit Exploratory Data Analysis

This project is an introductory exploratory data analysis project using the Titanic dataset and Streamlit.

Dataset:
data/titanic.csv

EDA Performed:
- Dataset preview
- Descriptive statistics
- Dataset dimensions
- Missing-value analysis
- Survival by sex
- Survival by passenger class
- Age distribution
- Fare distribution

Streamlit Application:
app.py
